# Security Audit Report

**Date:** 2026-06-09  
**Scope:** Full codebase scan of `KIMIK0T14/Ser-un-pelo`

---

## Summary

The repository contains two heavily obfuscated Lua scripts (`Code.lua`, `card.lua`) generated by the [WeAreDevs obfuscator](https://wearedevs.net/obfuscator), plus one MP3 audio file. The obfuscated scripts contain **Roblox exploit-level APIs** that pose serious security risks. Because the code is obfuscated, hidden URLs, API keys, or webhook endpoints **cannot be fully ruled out** — they may be buried under multiple encryption layers.

## Fixes Applied

1. **Added `.gitignore`** — prevents accidental commit of `.env` files, credentials, keys, and IDE configs.
2. **Added this `SECURITY_AUDIT.md`** — documents findings for future reference.

---

## Recommendations

1. **Replace obfuscated scripts with source code.** Obfuscated code cannot be audited, maintained, or trusted. If you wrote these scripts, commit the unobfuscated source instead.

2. **Remove exploit APIs.** Functions like `setclipboard`, `writefile`, `readfile`, `request`, `firetouchinterest`, and `FireServer` are exploit-level APIs typically used in Roblox cheating tools. If this is a legitimate Roblox project, these should not be present.

3. **Audit the `request` calls.** The `request` API combined with `JSONEncode` can exfiltrate player data (usernames, thumbnails, game state) to external servers. The destination URLs are hidden behind encryption.

4. **Remove or audit the MP3 file.** While the file is a valid audio file, its hash-based naming (`81a40f0c7fa22c44a4d88b7e25834036`) suggests it was programmatically generated or downloaded. Verify it is intentional.

5. **Add authentication.** If any part of this project communicates with external services, add proper authentication rather than hardcoding credentials in obfuscated code.

6. **Use environment variables for secrets.** Never embed API keys, webhook URLs, or tokens in source code — use environment variables or a secrets manager.
